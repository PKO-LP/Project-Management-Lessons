Выберите тему и заказчика My[название], затем создайте приложение за 6 недель.

- [Короткое задание студентам](student-project-starter/Задание.md).
- [Начало README для проекта](student-project-starter/README.md).
- [Семь шаблонов документации](student-project-starter/docs/).
- [Карточка проекта и все шаблоны одним файлом](student-project-starter/Все_шаблоны.md).
- [Скачать готовый набор ZIP](student-project-starter/MySoft_Старт_проекта.zip).

Скопируйте содержимое папки `student-project-starter` в репозиторий студента. Примеры и подсказки в квадратных скобках заменяйте данными своей темы. Код и тесты предстоит написать самостоятельно.

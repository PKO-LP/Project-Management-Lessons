# Командная работа на Python

У вас уже есть небольшая программа со списком записей. Выберите для неё **новую тему**. Например, это может быть список настольных игр, каталог комиксов или очередь треков для вечеринки. Определите, кто пользуется программой и что означает одна запись. Для каталога комиксов запись — это название комикса.

## 1. Откройте готовую программу

1. Скачайте [стартовую программу](Стартовая%20программа.py) и сохраните её как **main.py** в папке проекта.
2. В VS Code откройте эту папку через **Файл → Открыть папку**. Откройте **Терминал → Создать терминал** и выполните команду `python main.py`. Если Windows не находит команду `python`, попробуйте `py main.py`. Если доступна команда **Python: Run Python File in Terminal**, можно запустить через неё, выбрав установленный интерпретатор.
3. Добавьте запись, выведите список и завершите программу. При новом запуске список пуст. Записи пока хранятся только во время работы программы.

Если ни один запуск не сработал, продолжайте обсуждение и оформление в тетради. Код можно написать в VS Code и запустить на компьютере другого участника. Результат, который вы ещё не получили, запишите как ожидаемый.

## 2. Придумайте пять функций

Запишите в тетради название проекта и пять идей команды. Для каждой напишите, что получит пользователь, что может пойти не так и как это проверить. Риск — это конкретная проблема, например пользователь вводит номер записи, которой нет, и программа должна продолжить работу.

**Пример для каталога комиксов**

| Функция | Что сможет сделать пользователь | Что может пойти не так | Как проверим |
| --- | --- | --- | --- |
| Поиск по части названия | Найдёт «Лунный город», введя «лун». | Поиск может пропустить название из-за заглавной буквы. | Добавим «Лунный город», введём «лун» и проверим, что запись найдена. |

Теперь составьте такую же таблицу для своей темы. Можно менять способ поиска, порядок вывода, добавление или редактирование записей. Для каждой идеи придумайте свою проверку.

## 3. Напишите одну функцию вручную

Выберите из таблицы функцию, которая полезна пользователю и которую вы можете объяснить на базовом Python. Запишите, почему взяли её первой. Остальные четыре остаются в плане команды.

Распределите работу. Один участник пишет код, другой читает его вместе с ним и помогает разобраться, остальные готовят проверки. Если закончили, поменяйтесь и дайте другому участнику попробовать следующую функцию.

Добавьте в меню новый пункт и обработайте его в коде. Используйте знакомые конструкции: список, `input()`, `if`, `for`. Напишите код сами. Если забыли синтаксис, посмотрите в конспекте или попросите объяснить отдельную команду. Каждый должен понимать, как работает добавленный пункт меню.

## 4. Проверьте результат

Запустите программу. Проверьте новую функцию в обычной ситуации и в случае из вашей графы «Что может пойти не так». Затем убедитесь, что можно по-прежнему добавить и показать запись. Для каждой проверки запишите в тетради **действие, что ожидали и что получилось**. Если нашли проблему, попробуйте её исправить и повторите ту же проверку.

В конце покажите таблицу с пятью идеями в тетради и продемонстрируйте один запуск с новой функцией. Если запустить не удалось, покажите код и объясните, как проверите его на компьютере с Python.

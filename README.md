# Проектный менеджмент · 16 ноября

## Шпаргалка преподавателю

1. **Откройте нужную страницу.** 1-я пара (11 ТЭС) и 2-я пара (12 ТЭС) — [Управление изменениями](Управление%20изменениями.md). 3-я пара (11 ТЭС) — [Управление качеством](Управление%20качеством.md).
2. **Скажите группе.** «Откройте занятие. Запишите конспект и зарисуйте схему с пометкой «Зарисуйте». Выполните практическую по шагам, затем придумайте свою ситуацию для самостоятельного задания. Результат покажите на месте».
3. **Посмотрите главное.** На первых двух парах команда показывает общую таблицу и объясняет, что нужно сделать до запуска. На третьей показывает замечание о пропавших заказах после сброса фильтра: что должно было произойти и что произошло на самом деле. Полный список для показа есть в конце каждого задания.

## Студентам

Откройте занятие своей пары по ссылке выше. Лекция, схемы и все исходные данные для практической находятся на одной странице. Работу покажите на экране или в тетради.

**Для 1-й и 2-й пар.** Сначала посмотрите [заполненный пример про подкаст](Управление%20изменениями.md#рассмотрим-пример-ситуации-подкаст-выходит-в-эфир). Затем [разделитесь на команды и выберите свои проекты](Управление%20изменениями.md#практическая-работа-команда-перед-запуском).

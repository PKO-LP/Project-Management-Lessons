# Проектный менеджмент · 16 ноября

## Шпаргалка преподавателю

1. **Откройте нужную страницу.** 1-я пара (11 ТЭС) и 2-я пара (12 ТЭС) — [Управление изменениями](Управление%20изменениями.md). 3-я пара (11 ТЭС) — [Управление качеством](Управление%20качеством.md).
2. **Скажите группе.** «Откройте занятие своей пары. Запишите конспект, зарисуйте схему из раздела «В тетрадь» и выполните практическую по шагам. Результат покажите на месте».
3. **В конце.** На первых двух парах каждый выполняет всю практическую в своей тетради. Один участник показывает тебе свою таблицу целиком и объясняет решения команды. При необходимости попроси других показать их записи. На третьей показывает замечание о пропавших заказах после сброса фильтра.

## Студентам

Откройте занятие своей пары по ссылке выше. Лекция, схемы и все исходные данные для практической находятся на одной странице. На первых двух парах покажите работу в тетради. На третьей можно показать её на экране или в тетради.

**Для 1-й и 2-й пар.** Сначала посмотрите [заполненный пример про подкаст](Управление%20изменениями.md#рассмотрим-пример-ситуации-подкаст-выходит-в-эфир). Затем [откройте задание с готовой ситуацией про пиццерию](Управление%20изменениями.md#практическая-работа-команда-перед-запуском).

**Закончили основную работу?** На первых двух парах переходите к [дополнительным заданиям в тетради](Управление%20изменениями.md#дополнительные-задания).

- **Название:** [короткое название приложения].
- **Исполнитель:** [ФИО], 2 курс, 09.02.07 «Информационные системы и программирование».
- **Легенда:** вы работаете в студии «MyСофт». Заказчик My[название] поручил вам создать приложение для [процесс]. Сейчас сотрудники [как работают], поэтому [конкретная проблема].

## Установка и запуск

Это стартовый шаблон. Команды запуска приложения станут доступны после создания `src/main.py`.

1. Скачайте репозиторий и откройте его папку в терминале.
2. Установите Python 3.11 или новее с поддержкой Tkinter.
3. Выполните подготовку окружения:

```bash
python -m venv .venv
```

Активируйте окружение: Windows — `.venv\Scripts\activate`; macOS/Linux — `source .venv/bin/activate`.

```bash
python -m pip install -r requirements.txt
```

После реализации приложения:

```bash
python src/main.py
```
